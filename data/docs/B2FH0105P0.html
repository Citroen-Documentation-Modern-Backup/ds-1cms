B2FH0105P0Remplacement : Soufflets de transmissions
NOTA : Le bol de transmission côté roue n’est pas démontable ; Le remplacement d’un soufflet de transmission côté roue nécessite la dépose du soufflet côté réducteur.
1. Outillage
outil Référence Désignation
Figure : e5ab0rwt
 [0409] Pince pour pose des colliers de soufflets de transmissions
2. Opération préliminaire
Déposer les transmissions .
3. Présentation
Figure : b2fh018d
(1) Transmission gauche.
(2) Transmission droite.
4. Transmission gauche
4.1. Dépose : Côté réducteur
Figure : b2fh01bd
Déposer :
  • Les 2 colliers (4)
  • Le jonc (3)
Dégager le soufflet (5).
Enlever le maximum de graisse à l’intérieur du soufflet (5).
Figure : b2fh01ed
Déposer le bol (6).
Nettoyer l’excédent de graisse sur le tripode.
Figure : b2fh01hd
Déposer le circlips (7).
Figure : b2fh01kd
Déposer le tripode (8) ; À l’aide d’un marteau et d’un chasse-goupille (Si nécessaire).
Déposer le soufflet (5).
4.2. Dépose : Côté roue
Déposer : Le soufflet de transmission (5) (Côté réducteur).
Figure : b2fh01nd
ATTENTION : Éviter tout choc et toute détérioration de la piste magnétique ( en "a").
Déposer :
  • Les 2 colliers (9)
  • Le soufflet (10) (Par le côté réducteur)
4.3. Repose : Côté roue
ATTENTION : Remplacer les 2 colliers (9).
NOTA : Ne pas oublier de reposer les colliers et le soufflet avant de reposer le tripode .
Positionner :
  • Les 2 colliers (9)
  • Le soufflet (10)
Figure : b2fh01qd
Remplir l’intérieur du soufflet à l’aide de la graisse spécifique.
Reposer le soufflet (10).
Essuyer l’excédent de graisse.
Reposer : Les 2 colliers (9) ; À l’aide de l’outil [0409].
4.4. Repose : Côté réducteur
Remplacer systématiquement :
  • Les 2 colliers (4)
  • Le circlips (7)
  • Le jonc (3)
NOTA : Ne pas oublier de reposer les colliers et le soufflet avant de reposer le tripode .
Positionner :
  • Les 2 colliers (4)
  • Le soufflet (5)
Reposer :
  • Le tripode (8)
  • Le circlips (7)
  • Le bol (6)
Graisser le joint homocinétique à tripode à l’aide de la graisse spécifique.
Reposer le soufflet (5).
Essuyer l’excédent de graisse.
Reposer :
  • Les 2 colliers (4)
  • Le jonc (3)

Figure : b2fh01td

Figure : b2fh01wd

Figure : b2fh01zd

Figure : b2fh025d

Figure : b2fh028d

  • Les 2 colliers (17)
  • Le soufflet (18) (Par le côté réducteur)
5.3. Repose : Côté roue
ATTENTION : Remplacer les 2 colliers (17).

Positionner :
  • Les 2 colliers (17)
  • Le soufflet (18)

  • Le circlips (15)
  • Le jonc (13)
