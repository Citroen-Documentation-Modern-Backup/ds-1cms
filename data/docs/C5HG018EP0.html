C5HG018EP0Dépose - Repose : Circuit de chauffage
CONDUITE A GAUCHE
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Opérations préliminaires
Déposer :
  • La protection (Partie avant )
  • La protection (Partie centrale)
  • Le pare-boue (Partie centrale) (Côté conducteur)
Figure : c5hg0tcd
Déposer les 2 vis (1).
Désaccoupler les tuyaux .
Vidanger le circuit de chauffage.
Déposer la pompe à eau circuit de chauffage .
2. Dépose
Lever le véhicule.
Figure : c5hg0uqd
Dégager les colliers (3).
Désaccoupler le tuyau (2).
Déposer le tuyau (2).
Désaccoupler le tuyau (4).
Baisser le véhicule.
Figure : c5hg0urd
Dégrafer l’agrafe ( en "a").
Déposer l’ensemble réservoir liquide de chauffage / tuyau (4).
3. À l’établi
3.1. Déshabillage
Figure : c5hg0uud
Dégager le collier (5).
Désaccoupler le tuyau (4).
Déposer :
  • Le tuyau (4)
  • Le réservoir de liquide de chauffage (6)
3.2. Habillage
Accoupler le tuyau (4) au réservoir de liquide de chauffage.
Reposer le collier (5).
4. Repose
Reposer l’ensemble réservoir liquide de chauffage (6) / tuyau (4).
Agrafer l’agrafe ( en "a").
Lever le véhicule.
Accoupler le tuyau (4).
Reposer le tuyau (2).
Accoupler le tuyau (2).
Reposer les colliers (3).
5. Opérations complémentaires
Reposer la pompe à eau circuit de chauffage .
Accoupler les tuyaux .
Reposer les 2 vis (1).
Remplir et purger le circuit de chauffage.
Remplir le réservoir de liquide de chauffage jusqu’au niveau "FULL".
Mettre le contact.
Actionner la clé de contact pour obtenir l’affichage prêt "READY".
ATTENTION : Contrôler que le liquide de chauffage circule dans le réservoir.
Faire fonctionner le chauffage.
Couper le contact.
Remplir à nouveau le réservoir de liquide de chauffage jusqu’au niveau "FULL" (Si nécessaire).
Reposer :
  • Le pare-boue (Partie centrale)
  • La protection (Partie centrale)
  • La protection (Partie avant )
