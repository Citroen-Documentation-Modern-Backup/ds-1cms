D1AG0131P0Dépose - repose : Faisceaux électriques de puissance
IMPERATIF : Respecter les consignes de sécurité et de propreté .
IMPERATIF : Mettre le véhicule hors tension .
1. Opération préliminaire
Déposer la batterie de traction .
2. Dépose
ATTENTION : Répérer la position des faisceaux électriques avant la dépose.
Figure : d1ag09yd
Dégrafer : Les faisceaux électriques (en "a", "b", "c").
Figure : d1ag0a1d
Déposer les vis (1).
Desserrer les vis (2) (Sans déposer).
Descendre le véhicule.
Figure : d1ag0a4d
Déposer :
  • Les vis (3)
  • Le couvercle de protection (4)
Figure : d1ag0a7d
Déposer :
  • Les vis (6), (7)
  • Les vis (2)
  • Les faisceaux électriques de puissance (5)
3. Repose
ATTENTION : Respecter les couples de serrage : Éléments de la chaîne de traction électrique .
ATTENTION : Remplacer systématiquement les joints toriques des faisceaux électriques de la chaîne de traction.
Mettre en place : Les faisceaux électriques de puissance (5).
Reposer :
  • Les vis (2) (sans serrer)
  • Les vis (6), (7) (sans serrer)
Serrer :
  • Les vis (2)
  • Les vis (6), (7)
Reposer :
  • Le couvercle de protection (4)
  • Les vis (3)
Lever le véhicule.
Reposer les vis (1).
Agrafer : Les faisceaux électriques (en "a", "b", "c").
4. Opérations complémentaires
Reposer la batterie de traction .
IMPERATIF : Mettre le véhicule sous tension .
