D1AG013DP0Dépose - repose : Faisceau électrique de charge rapide
IMPERATIF : Respecter les consignes de sécurité et de propreté .
IMPERATIF : Seuls les personnels ayant reçu une formation spécifique aux véhicules électriques sont habilités à intervenir sur le véhicule (respecter la réglementation en vigueur dans le pays concerné).
1. Opérations préliminaires
IMPERATIF : Mettre le véhicule hors tension .
Déposer :
  • La batterie de traction
  • Le pare-boue arrière gauche
2. Dépose
Figure : d1ag0chd
Déposer la vis (1).
Dégrafer : Le faisceau électrique de charge rapide (2) (en "a", "b").
Figure : d1ag0ckd
Lever le véhicule.
Dégrafer :
  • Le faisceau électrique de servitude (3) (en "c")
  • Le faisceau électrique de charge rapide (2) (en "d", "e", "f", "g")
Figure : d1ag0cnd
Descendre le véhicule.
Ouvrir la trappe de charge rapide.
Déposer :
  • Les vis (4)
  • Le faisceau électrique de charge rapide (2) avec son support de fixation  (sous le véhicule)
Figure : d1ag0cqd
Déposer (à l’établi) :
  • Les vis (5)
  • Le support de fixation (6) du faisceau électrique de charge rapide (2)
3. Repose
Reposer :
  • Le faisceau électrique de charge rapide (2) sur son support de fixation (6)
  • Les vis (5)
Positionner : Le faisceau électrique de charge rapide (2) avec son support de fixation (6).
Reposer les vis (4).
Lever le véhicule.
Agrafer :
  • Le faisceau électrique de charge rapide (2) (en "d", "e", "f", "g")
  • Le faisceau électrique de servitude (3) (en "c")
  • Le faisceau électrique de charge rapide (2) (en "a", "b")
Reposer la vis (1).
4. Opérations complémentaires
Reposer :
  • Le pare-boue arrière gauche
  • La batterie de traction
IMPERATIF : Mettre le véhicule sous tension .
