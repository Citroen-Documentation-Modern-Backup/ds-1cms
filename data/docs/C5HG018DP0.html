C5HG018DP0Dépose - Repose : Pompe à eau circuit de chauffage
CONDUITE A GAUCHE
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Opérations préliminaires
Déposer :
  • La protection (Partie avant )
  • La protection (Partie centrale)
  • Le pare-boue (Partie centrale) (Côté conducteur)
Figure : c5hg0tcd
Déposer les 2 vis (1).
Désaccoupler les tuyaux .
Vidanger le circuit de chauffage.
Figure : c5hg0thd
Déposer :
  • Le bouchon (2)
  • Les 3 vis (3)
Écarter :
  • Le réservoir de liquide de chauffage
  • Le collier (4)
Désaccoupler le tuyau (5).
2. Dépose
2.1. Véhicule (Jusqu’au N° OPR 13203)
Figure : c5hg0tkd
Dégrafer l’agrafe  (en "a").
Lever et caler le véhicule.
Figure : c5hg0tnd
Dégrafer l’agrafe  (en "b").
Figure : c5hg0tqd
Déconnecter le connecteur  (en "c").
Déposer :
  • Les 2 vis (6)
  • La pompe à eau circuit de chauffage (7)
2.2. Véhicule (à partir du N° OPR 13204)
Figure : c5hg1msd
Dégrafer l’agrafe  (en "d").
Figure : c5hg1mtd
Déconnecter le connecteur  (en "e").
Déposer :
  • Les 2 vis (8)
  • La pompe à eau circuit de chauffage (9)
3. À l’établi
3.1. Déshabillage
Figure : c5hg1mud
Dégager les colliers (11).
Déposer les tuyaux (5), (10).
3.2. Habillage
Reposer :
  • Les tuyaux (5) et (10)
  • Les colliers (11)
4. Repose
ATTENTION : Respecter les couples de serrage .
4.1. Véhicule (Jusqu’au N° OPR 13203)
Reposer :
  • La pompe à eau circuit de chauffage (7)
  • Les 2 vis (6)
Connecter le connecteur  (en "c").
Agrafer l’agrafe  (en "b").
4.2. Véhicule (à partir du N° OPR 13204)
Reposer :
  • La pompe à eau circuit de chauffage (9)
  • Les 2 vis (8)
Connecter le connecteur  (en "e").
Agrafer l’agrafe  (en "d").
5. Opérations complémentaires
Accoupler les tuyaux .
Reposer les 2 vis (1).
Baisser le véhicule.
Agrafer l’agrafe  (en "a").
Accoupler le tuyau (5).
Reposer :
  • Le collier (4)
  • Le réservoir de liquide de chauffage
  • Les 3 vis (3)
Remplir et purger le circuit de chauffage.
Remplir le réservoir de liquide de chauffage jusqu’au niveau "FULL".
Mettre le contact.
Actionner la clé de contact pour obtenir l’affichage prêt "READY".
ATTENTION : Contrôler que le liquide de chauffage circule dans le réservoir.
Faire fonctionner le chauffage.
Couper le contact.
Remplir à nouveau le réservoir de liquide de chauffage jusqu’au niveau "FULL" (Si nécessaire).
Reposer :
  • Le bouchon (2)
  • Le pare-boue (Partie centrale)
  • La protection (Partie centrale)
  • La protection (Partie avant )
